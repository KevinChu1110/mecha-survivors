# 自訂素材外掛包

在這個資料夾放自己的角色圖片與 `pack.json`，遊戲啟動時會自動讀取並出現在角色選擇畫面。
除了本說明與 `pack.example.json` 之外，這個資料夾的內容都不會被 git 追蹤，也不會被推上 GitHub。

- `base`：沿用哪一位內建角色的技能組（`volt` 雷鋒、`blade` 赤焰、`shade` 暗影、`fang` 戰神）
- `replace`：要取代哪位內建角色；不寫就是新增一位
- `info`：覆寫名稱、定位、專屬能力說明、血量、移速等欄位
- `frames`：各動作的圖片（透明背景 PNG，角色預設面向右；面向左請設 `facesLeft: true`）
- 請只使用自己有權使用的素材
